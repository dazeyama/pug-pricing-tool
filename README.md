# PUG Pricing Tool

The buy counter for **Players' Union Games**, a worker-owned game store. Staff type what's
printed on a trading card, see the exact printing with condition-by-condition market prices,
and add it to the buy in one keypress. Every card bought, from a single walk-in to a whole
collection, lands in one shared record the store can look back on and export to inventory.

Magic: The Gathering and Pokémon (English and Japanese). Card data from Scryfall and TCGdex;
prices via JustTCG. Not affiliated with Wizards of the Coast or The Pokémon Company.
